## Estructura de Documentación

Toda la documentación técnica y arquitectónica del repositorio se encuentra normalizada bajo las siguientes carpetas:

- 📑 **[`INDEX.md`](INDEX.md)**: Índice maestro de manuales, diagramas, ADRs y gobernanza.
- 🚦 **[`STATUS.md`](STATUS.md)**: Estado actual de salud, compuertas de calidad, tokens y versiones.
- 📜 **[`LOG.md`](LOG.md)**: Registro histórico de decisiones, hitos y cambios materiales.
- 📋 **[`TODO.md`](TODO.md)**: Backlog activo y tareas pendientes bajo protocolo de 7 fases.
- 🗄️ **[`TODO_DONE/`](TODO_DONE/)**: Histórico inmutable de tareas completadas y archivadas.
- 🏛️ **[`adr/`](adr/README.md)**: Registro formal de Decisiones de Arquitectura (ADR-0001, ADR-0002).
- 📐 **[`diagrams/`](diagrams/)**: Diagramas Mermaid de arquitectura, gobernanza y flujos.
- 📘 **[`manual/`](manual/GUIA_ARQUITECTURA_HARNESS_Y_ENTORNO_AGY.md)**: Manuales de arquitectura del arnés y entorno AGY.
- 📁 **[`plan/`](plan/)**: Planes de requisitos, arquitectura e intervenciones de ingeniería.
- 🩺 **[`post-mortem/`](post-mortem/TEMPLATE_POSTMORTEM_5W.md)**: Plantillas y autopsias 5W post-incidencias SRE.
